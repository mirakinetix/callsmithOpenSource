# Callsmith Branding

## Official Product

**Callsmith** is an open-source API development and testing platform developed by **Mirakinetix**.

Official branding:

- Callsmith
- Mirakinetix
- Build. Automate. Scale.

Official website:

https://mirakinetix.com

## Attribution

Projects and distributions derived from Callsmith should preserve appropriate attribution to the original project and Mirakinetix.

A suitable attribution is:

> Based on Callsmith by Mirakinetix.

## Modified Versions

The Callsmith source code may be modified and redistributed according to the applicable software license.

Modified versions should clearly identify themselves as modified versions and should not imply that they are official Mirakinetix releases or that Mirakinetix endorses the modified distribution.

## Logos and Visual Identity

The Mirakinetix and Callsmith names, logos, and visual identity are used to identify the original project.

The software license does not grant permission to imply official affiliation, sponsorship, endorsement, or release by Mirakinetix.

## Branding Goal

Callsmith is intended to remain open and extensible while maintaining clear attribution to its original creator.

**Build. Automate. Scale.**
## Callsmith application and interface icons

The approved asset pack was supplied as Callsmith-Icons.zip. The local copy
used for this integration had 186 entries, passed ZIP CRC checks, and had this
SHA-256 digest:

    1D40656D85851A18A3F523AC32B4F330EDC723109B8747590B4976AABF442FE1

The archive manifest identifies Callsmith and Mirakinetix and describes the
individual artwork as redrawn from the generated concept sheet. Callsmith ships
unchanged originals selected from the pack:

- The 16, 32, 48, 64, 128 and 256 pixel app PNGs supply window icons.
- Callsmith.ico is passed to the Windows launcher build. It contains seven sizes,
  including 24 pixels.
- Callsmith.icns is passed to the macOS DMG build for either architecture.
- The selected 48 pixel interface PNGs use the original names from the archive.
  Existing controls display them through IconView. The current look and labels
  are retained in normal, hover, and disabled states.

The archive included no standalone license file. The existing branding and
attribution terms above still apply. The retained Lucide SVG fallback files
keep their attribution in LICENSES/LUCIDE-LICENSE.txt. The concept board,
oversized originals, and badges are reference material and are not required
at runtime. Unmapped controls retain their existing icons.
