# Callsmith Branding

## Official Product

**Callsmith** is an open-source API development and testing platform developed by **Mirakinetix**.

Official branding:

- Callsmith
- Mirakinetix
- Build. Automate. Scale.

Official website:

https://mirakinetix.com

## Attribution

Projects and distributions derived from Callsmith should preserve appropriate attribution to the original project and Mirakinetix.

A suitable attribution is:

> Based on Callsmith by Mirakinetix.

## Modified Versions

The Callsmith source code may be modified and redistributed according to the applicable software license.

Modified versions should clearly identify themselves as modified versions and should not imply that they are official Mirakinetix releases or that Mirakinetix endorses the modified distribution.

## Logos and Visual Identity

The Mirakinetix and Callsmith names, logos, and visual identity are used to identify the original project.

The software license does not grant permission to imply official affiliation, sponsorship, endorsement, or release by Mirakinetix.

## Branding Goal

Callsmith is intended to remain open and extensible while maintaining clear attribution to its original creator.

**Build. Automate. Scale.**
