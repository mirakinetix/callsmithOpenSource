# Callsmith beta feedback

Use the company-approved private channel provided by your manager. Use the
test identifier assigned by the manager. Share only fictional reproductions
and sanitized attachments. Keep API tokens, passphrases, production
credentials, confidential response data, internal URLs, and workspace
databases out of the report. Review screenshots and logs before attaching
them. Company-specific reports stay in the private channel.

**P0 — Critical.** Security or data integrity problem.
**P1 — Major.** A core workflow fails.
**P2 — Minor.** A defect or usability problem with a workaround.
**P3 — Enhancement.** A feature or improvement suggestion.

For routine issues, submit one report per reproducible problem and include the
scenario ID. The manager or pilot contact records the issue ID, checks for
duplicates, confirms severity, assigns a follow-up owner, and replies in the
same private channel. For potential P0, stop the affected workflow and notify
the manager and Mirakinetix pilot contact promptly through the agreed private
escalation route. Keep evidence under company controls.
